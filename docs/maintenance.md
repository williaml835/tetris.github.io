# Maintaining Tetris

GitHub Pages still serves the root `index.html`; JavaScript and CSS live in `assets/`. The repository name stays `tetris.github.io` to preserve links.

## Edit and publish

1. Edit `assets/js/game.js` for behavior or `assets/css/styles.css` for appearance.
2. Preview locally using the command in the main README.
3. Check Start, movement, rotation, hold, hard drop, pause/resume, and Restart.
4. Commit only Tetris files and push to `main`.

Keep the existing GitHub Pages publishing configuration. If configuring it from scratch, select `main` and `/ (root)` in the repository's Pages settings.
